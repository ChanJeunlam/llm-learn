# 学习路线 Roadmap

学习方向：大模型应用开发 + 底层算法；日学习 1–2 小时。此前 Python 入门课程已学过，从第 11 课继续。

| 课次 | 内容 | 产出 |
| --- | --- | --- |
| 11–12 | Git / GitHub / 分支 / CI | 课程 GitHub 仓库及测试工作流 |
| 13–14 | HTTP / JSON / REST API | 本地 HTTP 服务器和客户端 |
| 15–16 | OpenAI Responses API / 多轮会话 | CLI 聊天助手 |
| 17–18 | 应用重构、异常处理、质量测试 | 第一阶段综合实践 |
| 下一阶段 | NumPy、PyTorch、梯度下降 | 神经网络训练 |
| 后续 | Transformer、GPT、RAG、Agent、微调、部署 | 持续累积项目 |

每次课程更新：Markdown 原理和逐行讲解、代码、自动测试、`results/` 验证记录；实测与未执行内容必须区分。
