# 课程维护规范

- 本仓库是唯一主仓库；不新建同类课程主仓库。
- `docs/NN-title.md`：每课目标、概念、公式、逐行代码说明、操作步骤、练习及验收。
- `projects/`：可运行项目及依赖、测试；依赖尽可能固定兼容区间。
- `results/YYYY-MM-DD-*.md`：真实执行命令、预期与实际输出、测试结果、限制、CI URL。
- `.github/workflows/`：非付费离线 CI；线上 API 调用必须显式授权与成本约束。
- README 提供课程导航和快速运行入口；每次变更同步更新。
- 不上传 API 密钥、令牌、个人隐私、真实客户数据、原始私人对话或大尺寸训练数据。
- 区分「静态审查」「本地已执行」「GitHub Actions 运行」「真实 API 已调用」；没有证据不声称成功。
- 课程主要中文，英语专业词汇保留；代码关键行提供解释与工程意义。
